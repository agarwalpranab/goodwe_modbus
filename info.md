# Goodwe Modbus

A Home Assistant custom integration for monitoring Goodwe solar inverters over a local network using the Modbus protocol (UDP or TCP).

## Features

- **Dual Protocol Support** — UDP (port 8899) and TCP (port 502)
- **20+ Sensors** — PV production, grid, battery, and system health
- **UI Configuration** — set up via Settings → Devices & Services
- **Local Only** — no cloud, no external calls
- **Configurable Polling** — default 30 seconds, adjustable in options

## Requirements

- Home Assistant 2024.1.0 or newer
- Goodwe inverter accessible on the local network
